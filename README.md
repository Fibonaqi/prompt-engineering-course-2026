## 为什么重写（意义）

- **原文对中文语境不友好**：所据中文翻译版为机器翻译，表达生硬、术语不统一，阅读门槛高，例子还停留在 `text-davinci-003`/GPT-3.5 时代（"苹果计数""奇数求和"），与 2026 年严重脱节。
- **基于理解做知识更新优化**：不是照搬翻译，而是把机翻腔改写为通顺、术语统一的中文，将零散技巧重排为 **L0–L4 层次体系**并厘清关系，并为每个技巧标注"2026 年是否被模型内化 / 被框架接管"。
- **补上缺失的时间线**：新增第 08 章，从 2026 视角讲清"提示工程 → Harness 工程 / 上下文工程"的演进脉络与概念映射表。
- 本课程写作中参考了 dair-ai 原作及其中文翻译版，并基于 MIT 许可进行中文重写与增补；署名与许可详见 [声明.md](./声明.md) 与 [LICENSE](./LICENSE)。

## 一句话定位

**提示工程没死，它从"手工雕琢一句话"进化成了"设计整个系统如何把信息喂给模型"。** 这门课帮你把这两件事都搞懂。
